=======================
TCSpecial Documentation
=======================

TCSpecial's documents, which its site gives at ``docs/``. Each page here is
made from the ``.rst`` file of its name beside it; this one is made from
``README.rst``.

Start here
==========

- `Getting Started <getting-started.html>`__: from nothing to a vehicle
  flying on your desk, in about fifteen minutes.
- `TCS Design and Documentation <manual.html>`__: what TCSpecial is, the
  programs that make up the TCS software, and which document covers
  what. The rest of the TCS projects' documents are linked from it.

The manuals
===========

How to use each program.

- `tcspecial <tcspecial.html>`__: the flight software, and the reference
  for every node type, every attribute of a configuration and each
  example.
- `tcs-cfge <tcs-cfge.html>`__: the configuration editor.
- `tcs-moc <tcs-moc.html>`__: the simulated operations center.
- `tcs-sim <tcs-sim.html>`__: the payload simulator.
- `tcs-verify <tcs-verify.html>`__: the configuration checker.
- `tcs-conflict <tcs-conflict.html>`__: whether two configurations can be
  run at once.
